# jira-pr-demo-target

A deliberately tiny sample app — a feedback form with a plain textarea and
nothing else. Not a real product; this exists purely as the target repo
for demonstrating [jira-to-pr-workflow](https://github.com/juan-rome/jira-to-pr-workflow)
end to end: a real Jira ticket, implemented for real, in a real PR against
this repo.

## Run it

Open `index.html` directly, or serve it:

```bash
npx serve .
```

## Test

```bash
npm test
```
